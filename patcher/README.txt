스타폭스 어드벤처 한글 패치 v1.2.1f (GameCube)
===============================================

일본판 스타폭스 어드벤처(Rev 1) 이미지에 적용하는 한글 패치입니다.
게임 데이터는 들어 있지 않으며, 직접 소유한 디스크에서 만든 이미지가 필요합니다.


[사용법]

  1. 이 폴더에 원본 이미지를 넣고 「패치하기.bat」을 더블클릭합니다.
     또는 원본 이미지 파일을 「패치하기.bat」 위에 끌어다 놓습니다.
  2. 끝나면 원본과 같은 폴더에 「Star Fox Adventures (Korean).iso」가 생깁니다.
     원본 파일은 그대로 남습니다.

  처음 실행할 때 Windows가 경고하면 「추가 정보 → 실행」을 누르세요.
  Windows 10 이상에 기본으로 들어 있는 PowerShell을 사용합니다.

  결과 파일 이름을 바꾸려면 명령줄에서 두 번째 인자로 지정합니다.
    패치하기.bat "원본.iso" "D:\Games\스타폭스 어드벤처 한글.iso"


[원본 이미지]

  게임: 스타폭스 어드벤처 일본판 Rev 1 (게임 ID GSAJ01)

  패처가 게임 파일 하나하나를 원본과 비교하므로,
  덤프 방식에 따라 ISO 전체 MD5가 달라도 게임 파일만 같으면 적용됩니다.
  참고: Redump 정본 ISO는 1,459,978,240 바이트, MD5 ebff34930b3e8846167047bf71d25fbc 입니다.

  지원 형식          결과
  ---------------    ------
  ISO, GCM           ISO
  CISO, WIA, WDF,    ISO (동봉한 wit으로 ISO로 바꾼 뒤 적용)
  GCZ
  RVZ                지원 안 함 → Dolphin에서 ISO로 변환한 뒤 적용
                     (게임 우클릭 → 변환 → ISO)
  NKit               지원 안 함 → NKit 도구로 원래 ISO로 되돌린 뒤 적용

  북미판·유럽판, 이미 한글 패치를 적용한 이미지에는 적용되지 않습니다.


[오류 메시지]

  ~이(가) 아닙니다. 읽은 게임 ID      다른 게임이나 다른 지역판입니다.
  Rev 1 디스크가 아닙니다             Rev 0 등 다른 판입니다.
  원본 게임 파일이 다릅니다           이미 패치한 이미지이거나 손상된 덤프입니다.
  RVZ는 지원하지 않습니다             위 [원본 이미지] 표를 참고해 ISO로 바꾸세요.
  ISO로 변환하지 못했습니다           이미지가 손상됐거나 지원하지 않는 형식입니다.
  디스크 용량이 부족합니다            잘린 덤프일 가능성이 큽니다.


[실행]

  - Dolphin과 Wii U vWii + Nintendont 실기에서 엔딩까지 확인했습니다.
    Wii의 Nintendont도 같은 조건이라 문제없을 것으로 보입니다(미검증).
    게임큐브 실기(Swiss)는 검증하지 않았습니다.
  - 일본판 기준 패치라 세이브 데이터는 일본판 세이브와 호환됩니다.
    Dolphin 세이브(.gci)를 Nintendont로 옮길 때는 메모리 카드 이미지를
    일본어(Shift-JIS) 인코딩으로 만들어야 세이브 설명문이 깨지지 않습니다.


[패치로 생긴 문제가 아닌 것]  원래 게임의 동작입니다.

  - 자막이 영어 음성보다 짧거나 내용이 다름
      일본판 대사를 번역했습니다. 일본판은 북미판보다 대사를 간결하게 줄이거나
      바꾼 부분이 많아, 음성은 길게 이어지는데 자막은 짧을 수 있습니다.
  - 자막 타이밍
      자막이 음성보다 먼저 뜨거나 빨리 넘어가는 것처럼 보일 수 있습니다.
      자막이 뜨고 지워지는 시각은 일본판 원본 그대로입니다.
  - 타이머 UI의 콜론 위치
      원본의 콜론 글자가 숫자보다 작고 위쪽에 붙어 있어서 어긋나 보입니다.
  - 음성이 가끔 나오지 않음
      사용하시는 환경의 디스크 읽기 타이밍에 따라 가끔 그럴 수 있습니다.
      패치는 음성 데이터를 건드리지 않습니다.


[알려진 한계]

  - 배너(게임 목록·본체 메모리 카드 화면) 설명은 한글을 넣을 수 없어 영문 표기입니다.
  - 디스크를 읽을 수 없을 때만 나오는 오류 메시지 일부는 일본어로 남아 있습니다.
