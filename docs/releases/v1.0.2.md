번역 전체 재검수본을 반영한 버전입니다. 타이틀 로고와 게임 안 글자 폰트는 v1.0.1과 같습니다.

**원본 일본판 Rev 1 ISO에 적용하는 전체 패치입니다.** 이전 한글 패치를 적용한 ISO에는 덧씌울 수 없습니다.

## 변경 사항

- 번역 전체 재검수 결과 1,779줄(고유 문구 253개)을 반영했습니다.
- 메모리 카드·시스템 문구를 자연스럽게 다듬었습니다. 예를 들어 「파워 버튼」을 「전원 버튼」으로, 「빈 용량」을 「빈 공간」으로 바꿨습니다.
- 대사와 오브젝트 설명의 표현을 정리하고 조작 안내 문구를 명확하게 고쳤습니다.
- 검수 표현이 창 너비를 넘긴 15줄은 자막이 잘리지 않도록 한도 안에서 줄여 반영했습니다.
- 경로에 대괄호가 있으면 빌드 도구가 번역 JSON을 찾지 못하던 문제를 고쳤습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `sfa-korean-v1.0.2-malgun.zip` | 원본 일본판 Rev 1 | 맑은 고딕 Bold판. 패치 `sfa-korean-malgun.xdelta`와 사용자 설명서 `README.txt`. |
| `sfa-korean-v1.0.2-pretendard.zip` | 원본 일본판 Rev 1 | Pretendard Bold판. 패치 `sfa-korean-pretendard.xdelta`와 사용자 설명서 `README.txt`. |

두 폰트판 중 하나만 적용하세요. 번역 내용은 같고 게임 안 글자 폰트만 다릅니다.

## 적용 방법

1. ZIP을 풀고 Delta Patcher에서 원본 ISO와 원하는 폰트의 `.xdelta`를 골라 적용합니다. 명령줄에서는 다음처럼 적용합니다.

   ```bash
   xdelta3 -d -s "Star Fox Adventures (Japan) (Rev 1).iso" sfa-korean-pretendard.xdelta "Star Fox Adventures (Korean).iso"
   ```

2. 결과 ISO의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README.txt`를 참고하세요.
