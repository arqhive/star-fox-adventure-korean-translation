# v1.1 - 스타폭스 어드벤처 한글 패치

타이틀 로고를 더 깔끔하게 다듬었습니다. 번역과 게임 내 폰트는 v1.0.2와 동일하며, 두 폰트판 모두 같은 로고를 사용합니다.

## 변경 사항

- 영문 `STARFOX ADVENTURES` 명판 아래에 남아 있던 일본어 로고의 노란 선·베벨 조각을 제거했습니다.
- 한글 두 줄의 크기와 간격을 조정해 외곽선이 붙지 않도록 했습니다. 공간 확보를 위해 제목 크기는 조금 줄였습니다.
- 로고 배치 계산에 실제 외곽선 두께와 줄 사이 여백을 반영했습니다.
- 기존 한글 ISO의 로고만 바꾸는 `tools/replace_logo.py`를 추가했습니다.

## 내려받기

번역 내용은 같고 게임 안 글자 폰트만 다릅니다. 하나만 적용하세요. ZIP에는 xdelta 패치와 설명서만 들어 있습니다.

| 파일 | 폰트 | 결과 ISO MD5 |
|---|---|---|
| `sfa-korean-v1.1-malgun.zip` | 맑은 고딕 Bold | `c9b1f3a673e96e8a79e6c17cda5d4aef` |
| `sfa-korean-v1.1-pretendard.zip` | Pretendard Bold | `9365e36151888c3013547d6c9fa3c634` |

## 원본 ISO와 적용 방법

- 스타폭스 어드벤처 **일본판 Rev 1**, 게임 ID `GSAJ01`
- 크기: `1,459,978,240` 바이트
- MD5: `ebff34930b3e8846167047bf71d25fbc`
- 기존 한글판에 덧씌우는 패치가 아닙니다. 원본 일본판 ISO에 적용하세요.

Delta Patcher에서 원본 ISO와 원하는 `.xdelta`를 선택하거나 다음 명령을 사용하세요.

```bash
xdelta3 -d -s "Star Fox Adventures (Japan) (Rev 1).iso" sfa-korean-pretendard.xdelta "Star Fox Adventures (Korean).iso"
```

## 검증

- 각 v1.0.2 폰트판과 비교해 바뀐 내부 파일은 `gamefront/TEX0.bin`, `gamefront/TEX0.tab` 두 개뿐입니다. 수정 텍스처는 455번 타이틀 로고 한 장입니다.
- 그 외 모든 디스크 파일과 DOL은 기존 각 폰트판과 바이트 단위로 동일합니다.
- 새 ISO에서 추출한 CMPR 로고가 압축 미리보기와 일치합니다. 두 줄 글자 마스크 사이의 최소 거리는 18픽셀로, 양쪽 외곽선 반경을 제외한 명목상 간격은 4픽셀입니다.
- 두 배포 패치를 원본 ISO에 다시 적용해 결과 ISO의 해시가 위 값과 일치하는지 확인했습니다.
- **v1.1 수정 로고는 사용자 게임 실행 확인을 마쳤습니다.** 이전 버전에는 Dolphin과 Wii U vWii + Nintendont 플레이 확인 기록이 있습니다.

## 알려진 한계

- 게임 목록·메모리 카드 화면의 배너 설명은 영문입니다.
- 디스크 읽기 오류 메시지 일부는 일본어로 남아 있습니다.
- 게임큐브 실기(Swiss)는 미검증입니다.

개인이 만든 비공식 팬 번역이며 Nintendo, Rare와 아무런 관련이 없습니다. 정품을 소유한 사람이 자신의 디스크에서 만든 이미지에 적용하세요. 패치를 적용한 ISO를 배포하거나 판매하지 마세요.
