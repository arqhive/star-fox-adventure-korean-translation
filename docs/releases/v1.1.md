타이틀 로고를 다듬은 버전입니다. 번역과 게임 안 글자 폰트는 v1.0.2와 같고, 두 폰트판 모두 같은 로고를 씁니다.

**원본 일본판 Rev 1 ISO에 적용하는 전체 패치입니다.** 이전 한글 패치를 적용한 ISO에는 덧씌울 수 없습니다.

## 변경 사항

- 영문 `STARFOX ADVENTURES` 명판 아래에 남아 있던 일본어 로고의 노란 선과 베벨 조각을 지웠습니다.
- 한글 두 줄의 크기와 간격을 조정해 외곽선이 서로 붙지 않게 했습니다. 공간을 확보하려고 제목 크기를 조금 줄였습니다.
- 로고 배치 계산에 실제 외곽선 두께와 줄 사이 여백을 반영했습니다.
- 기존 한글 ISO의 로고만 바꾸는 `tools/replace_logo.py`를 추가했습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `sfa-korean-v1.1-malgun.zip` | 원본 일본판 Rev 1 | 맑은 고딕 Bold판. 패치 `sfa-korean-malgun.xdelta`와 사용자 설명서 `README.txt`. |
| `sfa-korean-v1.1-pretendard.zip` | 원본 일본판 Rev 1 | Pretendard Bold판. 패치 `sfa-korean-pretendard.xdelta`와 사용자 설명서 `README.txt`. |
| `SHA256SUMS.txt` | | 두 ZIP의 SHA-256 값. |

두 폰트판 중 하나만 적용하세요. 번역 내용은 같고 게임 안 글자 폰트만 다릅니다.

## 적용 방법

1. ZIP을 풀고 Delta Patcher에서 원본 ISO와 원하는 폰트의 `.xdelta`를 골라 적용합니다. 명령줄에서는 다음처럼 적용합니다.

   ```bash
   xdelta3 -d -s "Star Fox Adventures (Japan) (Rev 1).iso" sfa-korean-pretendard.xdelta "Star Fox Adventures (Korean).iso"
   ```

2. 결과 ISO의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README.txt`를 참고하세요.
