최종판의 말투와 호칭을 다듬은 판입니다. 대사 80여 줄을 원문과 대조해 시리즈 문체(스타폭스 제로 v1.2f 기준)에 맞췄습니다. 화면·폰트·실행 코드는 v1.2f와 같습니다.

**원본 일본판 Rev 1 이미지에 적용하는 패치입니다.** 이전 한글 패치를 적용한 이미지에는 덧씌울 수 없습니다.

## 변경 사항

- 페피의 하게체를 노병 반말로 바꿨습니다(29줄, `작업 중이란 말이다!`). 하게체는 페퍼 장군만 씁니다.
- 화자가 분명하지 않은 월드맵 경고 4개는 페퍼·페피 누가 말해도 어색하지 않은 말투로 맞췄습니다(`폭스, 어디 가는 거지?`).
- 원문이 깔보지 않는 `ヤツ`를 `놈`에서 `녀석`으로 바꿨습니다(23줄). `貴様`는 `네놈`, `お前`는 `너`로 맞췄습니다(9줄).
- 폭스와 팔코의 딱딱한 어미를 편한 말로 풀었습니다(`돌아갈게`, `스타폭스에 복귀야` 등 4줄).
- 한 줄짜리 UI 안내문에서 마침표를 뺐습니다(`A 버튼을 누르세요` 등 4곳).
- 상점의 마인 사탕 설명을 원문대로 명사형으로 끝냈습니다(`워프 마인이 무척 좋아하는 것.`).

## 배포 파일

| 파일 | 설명 |
|---|---|
| `GSAJ_KPatch_v1.2.1f.zip` | 파일 단위 패처(`패치하기.bat`), 사용자 설명서 `README.txt` |
| `SHA256SUMS.txt` | ZIP의 SHA-256 값 |

## 적용 방법

1. ZIP을 풀고, 풀린 폴더에 원본 이미지를 넣습니다.
2. `패치하기.bat`을 더블클릭합니다. 원본 파일을 `패치하기.bat` 위에 끌어다 놓아도 됩니다.
3. 같은 폴더에 `Star Fox Adventures (Korean).iso`가 생깁니다.

| 원본 형식 | 결과 |
|---|---|
| ISO, GCM | ISO |
| CISO, WIA, WDF, GCZ | ISO |
| RVZ, NKit | 지원 안 함(ISO로 되돌린 뒤 적용) |

## 패치로 생긴 문제가 아닌 것

- **자막이 영어 음성보다 짧거나 내용이 다름**: 일본판 대사를 번역했습니다. 일본판은 북미판보다 대사를 간결하게 줄이거나 바꾼 부분이 많습니다.
- **자막 타이밍**: 자막이 뜨고 지워지는 시각은 일본판 원본 그대로입니다.
- **타이머 UI의 콜론 위치**: 원본 콜론 글자가 숫자보다 작고 위쪽에 붙어 있어서 그렇게 보입니다.
- **음성이 가끔 나오지 않음**: 사용하는 환경의 디스크 읽기 타이밍 때문입니다. 패치는 음성 데이터를 건드리지 않습니다.
