최종판입니다. 2회차 엔딩까지 플레이 검수를 마쳤습니다.

**원본 일본판 Rev 1 이미지에 적용하는 패치입니다.** 이전 한글 패치를 적용한 이미지에는 덧씌울 수 없습니다.

## 변경 사항

- 게임 안 글자 폰트를 G마켓 산스 Bold로 바꿨습니다. 폰트판은 하나로 합쳤습니다(맑은 고딕판·Pretendard판은 v1.1까지).
- 한글 글자의 높이를 원본 일본어 글자 기준선에 맞춰, 버튼 아이콘과 나란히 보이게 했습니다.
- 버튼 안내 글자(공격·되돌리기 등)를 2px 줄여 띠 아래 테두리에 닿지 않게 했습니다. 같은 파일을 쓰는 C메뉴 항목·마법 이름도 함께 작아졌습니다.
- 반말·존댓말을 장면마다 인물 관계에 맞게 정리했습니다. 일본어의 정중체·보통체 순간 전환은 장면의 기본 높임으로 맞추고, 혼잣말과 관계 변화는 살렸습니다.
- 2회차 엔딩까지 플레이 검수를 반영했습니다. 트리키 구출 장면의 뒤집힌 문장 순서, 워프 마인·슬리피·트리키 대사, 아기 찾기 부탁의 높임, 슬리피 힌트 어미 등을 고쳤습니다.
- 줄 넘침 검사를 개선했습니다. 버튼 아이콘을 실제 폭(22~24px)으로 재고, 슬리피 힌트 창 한도를 따로 잽니다. 이 검사로 찾은 24줄을 고쳤습니다.
- 배포 방식을 ISO 통째 xdelta에서 파일 단위 패처(`패치하기.bat`)로 바꿨습니다. 덤프마다 ISO 전체 MD5가 달라도 적용되고, CISO·WIA·WDF·GCZ도 받습니다. 별도 패치 도구가 필요 없습니다.
- README에 「패치로 생긴 문제가 아닌 것」(자막 길이·타이밍, 타이머 콜론, 음성)을 적었습니다.

## 배포 파일

| 파일 | 설명 |
|---|---|
| `sfa-korean-v1.2f.zip` | 파일 단위 패처(`패치하기.bat`), 사용자 설명서 `README.txt` |
| `SHA256SUMS.txt` | ZIP의 SHA-256 값 |

## 적용 방법

1. ZIP을 풀고, 풀린 폴더에 원본 이미지를 넣습니다.
2. `패치하기.bat`을 더블클릭합니다. 원본 파일을 `패치하기.bat` 위에 끌어다 놓아도 됩니다.
3. 같은 폴더에 `Star Fox Adventures (Korean).iso`가 생깁니다.

| 원본 형식 | 결과 |
|---|---|
| ISO, GCM | ISO |
| CISO, WIA, WDF, GCZ | ISO |
| RVZ, NKit | 지원 안 함(ISO로 되돌린 뒤 적용) |

## 패치로 생긴 문제가 아닌 것

- **자막이 영어 음성보다 짧거나 내용이 다름**: 일본판 대사를 번역했습니다. 일본판은 북미판보다 대사를 간결하게 줄이거나 바꾼 부분이 많습니다.
- **자막 타이밍**: 자막이 뜨고 지워지는 시각은 일본판 원본 그대로입니다.
- **타이머 UI의 콜론 위치**: 원본 콜론 글자가 숫자보다 작고 위쪽에 붙어 있어서 그렇게 보입니다.
- **음성이 가끔 나오지 않음**: 사용하는 환경의 디스크 읽기 타이밍 때문입니다. 패치는 음성 데이터를 건드리지 않습니다.
