마침표 검수를 반영한 버전입니다. 대사와 자막은 v1.0과 같고, 아이템·오브젝트 설명과 시스템 문구만 바뀌었습니다.

**원본 일본판 Rev 1 ISO에 적용하는 전체 패치입니다.** 이전 한글 패치를 적용한 ISO에는 덧씌울 수 없습니다.

## 변경 사항

- 문장으로 끝나는데 마침표가 없던 아이템·오브젝트 설명과 시스템 문구 51개(56곳)에 마침표를 붙였습니다. 「보물 상자」 「하이 스코어」 「예/아니요」처럼 명사구나 메뉴 항목인 문구는 그대로 뒀습니다.
- 마침표 때문에 창 너비를 넘긴 두 줄을 줄였습니다. 「잡아서 움직일 수 있다.」는 「잡아서 옮길 수 있다.」로, 「샤프클로만 들 수 있다.」는 「이들만 들 수 있다.」로 바꿨습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `sfa-korean-v1.0.1-malgun.zip` | 원본 일본판 Rev 1 | 맑은 고딕 Bold판. 패치 `sfa-korean-malgun.xdelta`와 사용자 설명서 `README.txt`. |
| `sfa-korean-v1.0.1-pretendard.zip` | 원본 일본판 Rev 1 | Pretendard Bold판. 패치 `sfa-korean-pretendard.xdelta`와 사용자 설명서 `README.txt`. |

두 폰트판 중 하나만 적용하세요. 번역 내용은 같고 게임 안 글자 폰트만 다릅니다.

## 적용 방법

1. ZIP을 풀고 Delta Patcher에서 원본 ISO와 원하는 폰트의 `.xdelta`를 골라 적용합니다. 명령줄에서는 다음처럼 적용합니다.

   ```bash
   xdelta3 -d -s "Star Fox Adventures (Japan) (Rev 1).iso" sfa-korean-pretendard.xdelta "Star Fox Adventures (Korean).iso"
   ```

2. 결과 ISO의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README.txt`를 참고하세요.
