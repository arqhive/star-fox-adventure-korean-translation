게임 화면에서 타이틀 로고 테두리가 흐려 보이던 문제를 고친 버전입니다. 번역 내용은 v0.9.0과 같습니다.

**원본 일본판 Rev 1 ISO에 적용하는 전체 패치입니다.** 이전 한글 패치를 적용한 ISO에는 덧씌울 수 없습니다.

## 변경 사항

- 원본 일본판 로고와 같은 테두리 구조(노란 글자, 남색 윤곽, 은색 베벨, 청록 테두리, 광채)로 로고를 다시 그렸습니다.
- 게임이 원본 로고 모양 밖을 흐리게 표시하므로, 한글을 원본 글자 영역 안에 맞춰 배치했습니다.
- 면책 조항을 추가했습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `sfa-korean-v0.9.1-malgun.zip` | 원본 일본판 Rev 1 | 맑은 고딕 Bold판. 패치 `sfa-korean-malgun.xdelta`와 사용자 설명서 `README.txt`. |
| `sfa-korean-v0.9.1-pretendard.zip` | 원본 일본판 Rev 1 | Pretendard Bold판. 패치 `sfa-korean-pretendard.xdelta`와 사용자 설명서 `README.txt`. |

두 폰트판 중 하나만 적용하세요. 번역 내용은 같고 게임 안 글자 폰트만 다릅니다.

## 적용 방법

1. ZIP을 풀고 Delta Patcher에서 원본 ISO와 원하는 폰트의 `.xdelta`를 골라 적용합니다. 명령줄에서는 다음처럼 적용합니다.

   ```bash
   xdelta3 -d -s "Star Fox Adventures (Japan) (Rev 1).iso" sfa-korean-pretendard.xdelta "Star Fox Adventures (Korean).iso"
   ```

2. 결과 ISO의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README.txt`를 참고하세요.
