# 파일 포맷 메모

## 디스크

- 북미판(GSAE01)과 일본판(GSAJ01) Rev 1은 main.dol을 포함해 `opening.bnr`만 빼고 전부 동일. 언어는 지역으로 결정되므로 일본판에서 `Japanese.bin`을 교체
- 원본 파일 데이터는 약 780MB에서 끝남 → 수정 파일은 그 뒤(0x8000 정렬)에 이어 쓰고 FST 엔트리의 오프셋·크기만 수정

## gametext

- `gametext/<구역>/<언어>.bin` 72개, `gametext/Sequences/<번호>_<언어>.bin` 132개(컷신 자막)
- 구조(빅엔디언)
  - `u32` 문자 수, 문자표 16바이트×n: UCS4, xpos, ypos(u16), left, right, top, bottom(s8), w, h, font, texture(u8)
  - `u16` 텍스트 수, `u16` 문자열 풀 크기, 텍스트 12바이트×n: id, 줄 수, window, alignH, alignV, lang, 첫 줄 인덱스(u32)
  - `u32` 줄 수, `u32` 오프셋×n, UTF-8 문자열 풀(4바이트 정렬)
  - `u32`, 텍스처(`u16 fmt, u16 bpp, u16 w, u16 h` + 데이터; fmt 2 = I4, 8x8 블록 순서 / fmt 1 = 16bpp 버튼 아이콘), 끝에 0×8
- 제어코드는 사설 영역 문자 + 바이너리 인자(00 포함 가능 → 널 기준으로 자르면 안 됨)
  - `U+F8F4`+2, `U+F8F7`+2(폰트 전환: 0002 버튼 아이콘, 0005 통역 아이콘), `U+F8FF`+8(RGBA 색), `U+E000`+2, `U+E018`+6(자막 타이밍), `U+E020`+2(힌트 구역), `U+F8F8/F8F9/F8FA`+0
- 일본어는 줄마다 별도 문자열(수동 줄바꿈), 영어는 긴 문장 자동 줄바꿈이고 힌트 내용 자체가 다름
- 글리프 메트릭: 셀 높이 21(top+h+bottom), 전각 advance 21, 아틀라스 1px 간격, 폭 512

## 텍스처 (TEX0/TEX1)

- `.tab` 엔트리: 상위 바이트 플래그, 하위 24비트×2 = `.bin` 오프셋
- `.bin` 항목: `ZLB\0`, u32 버전(1), u32 해제 크기, u32 압축 크기, zlib 데이터
- 해제 데이터: 0x60 헤더(w @0x0A, h @0x0C, GX 포맷 @0x16) + 픽셀. 데이터 영역은 이미지 크기의 2배로 잡혀 있고 뒤쪽은 미사용
- GX 포맷 3 IA8, 5 RGB5A3(4x4 블록), 6 RGBA8(4x4 블록), 14 CMPR(8x8 안 4x4 서브블록)
- 타이틀 로고: `gamefront/TEX0` 인덱스 454·456(영문 512x128), 455(일본어 512x191 CMPR)

## 배너

- `opening.bnr`(BNR1): 0x20부터 96x32 RGB5A3(4x4 블록) 이미지(글자 없는 엠블럼), 0x1820 이후 이름·제작사·설명 텍스트(Shift-JIS)

## 실행 파일 내장 텍스트

- main.dol 0x2C6F00 부근에 디스크 오류 메시지(UTF-8 일본어)와 전용 글리프 데이터. 디스크 읽기 오류 때만 사용
